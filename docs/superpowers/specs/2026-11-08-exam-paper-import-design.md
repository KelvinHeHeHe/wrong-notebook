# 任务 03：考试管理与整卷导入设计

## 意图

为家庭用户增加一条独立的外部试卷导入链路：把 1～20 页 PDF 或照片保存为本地试卷草稿，使用现有视觉模型按页识别题目，允许家长校对题号、区域、题干、答案和分值，确认后复用现有试卷详情、打印与答案页。

任务 03 只建立“可打印的外部试卷”，不创建错题、不识别孩子作答、不计算成绩趋势；这些行为分别属于任务 04 和任务 05。

## 目标

- 文字型 PDF 与扫描 PDF 都在浏览器端渲染为有序 JPEG 页图，保留版面和题目区域。
- 支持 1～20 页 PDF，或 1～20 张 JPEG/PNG/WebP/HEIC 照片；照片沿用现有方向校正、压缩和尺寸限制。
- 草稿页图和识别结果实时保存到 SQLite，刷新或单页失败不丢失其他页面。
- 按页调用现有 `splitQuestionsForUser`，复用用户 AI Provider、额度、路由和后台任务记录。
- 人工可修改试卷元数据、题号、页码、区域、题干、答案、解析、题型和分值。
- 人工可新增、删除和重排题目；漏题用“新增题目 + 框选区域”补齐，错误合题用新增/删除和区域编辑纠正。
- 发布前验证所有题目页均已识别、题干非空、区域合法、分值合法且标称总分一致。
- 全流程按当前用户隔离；外部试卷发布前后都不产生 `ErrorItem` 或 `PracticeRecord`。

## 非目标与反目标

- 不增加 Python OCR 服务，不绕过现有 AI Provider 层。
- 不在服务端解析原始 PDF；浏览器只上传受限、压缩后的页图。
- 不复用现有导入批次的“写错题本”动作，也不把外部卷题目伪装成错题。
- 不在任务 03 识别答案卷、批改作答、创建成绩或趋势图。
- 不为进度引入新的队列、Redis、对象存储或第二套数据库。
- 不为页面识别状态追加数据库字段或升级备份版本；状态从试卷状态和该页现有题目推导。

## 约束

- 沿用 Next.js 16、React 19、TypeScript、Prisma 5 和 SQLite。
- 每页压缩后不超过现有 1.5 MB 限制；每卷最多 20 页。
- 只接受图片 data URL；服务端重新校验 MIME、尺寸、数量和 checksum，不能信任浏览器元数据。
- `ExamPaper.origin='imported'`、`mode='original'`、`scope='all'`、`difficulty='original'`。
- 识别草稿不关联 `ErrorItem`；使用稳定的本地 `sourceShortId` 占位符。
- 已发布试卷在本任务中不重新运行识别；后续更正只走现有安全编辑能力。
- 中英文翻译 key 必须一致，页面移动优先，lint 零警告。

## 方案比较

### 方案 A：专用考试导入流程，复用底层解析能力（采用）

新建考试导入领域模块和 API，复用 PDF 渲染、图片压缩、AI 分题、区域编辑和现有试卷详情。优点是数据边界清晰，不会误写错题本，且与任务 04 的作答链路自然衔接；代价是需要一套轻量的导入与校对 UI。

### 方案 B：复用 `ImportBatch` 后再转换为试卷

优点是现有草稿 UI 和断点状态较完整；缺点是 `ImportBatch` 的终点是 `ImportTask`/`ErrorItem`，强行复用会把试卷题目错误地写入错题历史，或需要大规模拆解现有状态机，违反“优先复用、禁止无必要重写”的约束。

### 方案 C：全部在浏览器保存草稿，确认时一次写库

实现较少，但刷新、崩溃或第 19 页识别失败会丢失整卷工作，无法满足单页失败不影响其他页和可重试的验收要求。

## 数据与状态

### 试卷状态

```text
importing --保存全部页--> review --发布校验--> ready
    |                         ^
    +--单页识别失败------------+
```

- `importing`：页图已保存，尚未完成一次全卷识别。
- `review`：全卷识别请求已结束；有题目的页面视为已识别，无题目的题目页视为失败/待重试。
- `ready`：人工发布完成，进入现有详情和打印流程。
- `failed` 只用于创建阶段无法形成可恢复草稿的异常；单页失败不把整卷置为 `failed`。

`ExamPaperPage` 不新增状态字段：当试卷为 `importing` 时页面显示“待识别”；进入 `review` 后，存在 `ExamQuestion.pageNumber=page.order` 的题目页显示“已识别”，否则显示“识别失败，可重试”。答案页不要求产生题目。

页面 `order` 始终表示全卷物理页序，不按 `role` 分组重新编号。所有上传页默认是 `questions`；校对时可切换为 `answer_key`。切换为答案页会在同一事务中删除该页未发布题目，切回题目页后必须重新识别或人工新增题目。任务 03 只保存答案页原图，不从答案页自动提取答案。

### 按页识别写入

每个页面独立调用视觉模型。只有模型返回至少一道有效题目时，事务才替换该页旧草稿；失败或空结果保留原有题目。成功后根据页码和页内顺序重新生成全卷连续 `order`，其他页题目及人工修改保持不变。

区域使用 `DraftRegion[]` JSON 存入 `ExamQuestion.regionJson`，兼容跨栏题干和配图；读取时同时接受旧的单对象形式。AI 分题没有原生置信度时不伪造精确概率：存在 `unclear`、`partial` 或 `unlocated` 标志的题目保存较低置信提示，否则保存 `null`，由 UI 统一要求人工复核。

校对请求中的题目 `id` 可选：带有本卷现有 ID 的项目更新原题，不带 ID 的项目新建；本卷现有但请求中省略的题目删除。请求数组顺序成为全卷连续 `order`。跨卷 ID 一律拒绝，且上述替换仅允许尚未发布的外部试卷，因此不会破坏作答历史。

### 发布不变量

- 试卷属于当前用户且 `origin='imported'`。
- 至少一页 `questions` 页和一道有效题目。
- 每个 `questions` 页至少关联一道题；失败页必须重试或改为答案页。
- 题号可空，但题干必须非空；页码必须指向本卷题目页；区域必须在 0～1 范围。
- 单题分值为空或在现有 0～1000、一位小数限制内。
- `totalScore` 有值时，所有题目必须有分值且分值和与它一致；为空时按已有分值求和，没有完整分值则保持空。
- 发布事务只更新试卷和题目，不创建错题或练习记录。

## API

### `POST /api/exams/import`

接收元数据和 1～20 个已压缩页图，校验学科归属、MIME、页序、尺寸和重复 checksum，在一个事务中创建 `imported/importing` 试卷及页面。返回 `paperId` 和页面摘要。

### `POST /api/exams/:id/pages`

仅允许修改当前用户尚未发布的外部试卷。按物理 `order` 幂等追加或替换页面；同一物理页序不能因不同 `role` 重复存在。替换题目页时删除该页未发布的识别草稿并把试卷恢复为 `importing`；切换为答案页时同样删除该页题目。

### `POST /api/exams/:id/recognize`

接收 1～20 个页序；逐页调用 `splitQuestionsForUser`，每页独立持久化并返回 `successes`/`failures`。请求结束后把仍为 `importing` 的试卷转为 `review`。重复识别只替换指定页，失败不删除旧草稿。

### `PATCH /api/exams/:id`

在现有配图、分值和分组更新分支之前识别 `kind='import-draft'` 请求，原子更新外部卷元数据、页面角色与有序题目；题目支持新增、更新、删除和重排。`publish=true` 时执行发布不变量并转为 `ready`。其他现有请求格式和行为保持不变。

### `GET /api/exams` 与 `GET /api/exams/:id`

列表增加来源与考试元数据；详情增加页图和外部题目字段。生成试卷的现有响应字段保持兼容。

## 客户端流程

1. 考试列表新增“导入整卷”入口，进入 `/exams/import`。
2. 填写标题、学科、年级学期、考试类型、考试日期和可选满分。
3. 选择 PDF 或有序照片。PDF 全部按推荐方案渲染为页图；照片使用现有图片流水线压缩。
4. 预览、调整页序和删除页面，提交后创建本地草稿。
5. 页面依次请求单页识别并显示进度；单页失败不停止后续页面。
6. 跳转 `/exams/:id/import` 校对。页卡显示原图、识别状态和题目；可切换题目页/答案页。题目可新增、删除、重排、编辑，并用现有 `RegionEditorDialog` 调整区域；拆分或合并通过这些基础动作完成。
7. 保存草稿或发布。发布成功后进入现有 `/exams/:id` 详情，可打印题目与答案。

## 错误与恢复

- 超过 20 页、非法 MIME、超大页图、重复页序和重复 checksum 在入库前返回明确校验错误。
- PDF 加密、损坏或渲染失败留在客户端选择页，不创建半份试卷。
- 单页 AI 失败返回稳定错误码，继续识别其余页面；校对页提供该页重试。
- 权限和跨用户学科/试卷统一返回 404 或校验错误，不泄露对象存在性。
- 发布失败保持 `review` 和全部草稿，不产生学习历史副作用。

## 测试与验收

- 纯函数单测：页图 schema、checksum、区域兼容解析、题目映射、发布校验。
- API 集成测试：归属、1～20 页限制、幂等替换、单页部分失败、重试保留、发布事务和零错题副作用。
- 组件单测：PDF 全页渲染、照片排序、失败页提示、题目编辑和发布按钮状态。
- Playwright：导入两页图片、模拟一页识别失败、单页重试、校对并发布、进入现有打印页。
- 95% 边界/题号准确率需要用户提供或后续建立数学、语文、英语家庭样本集；本任务交付可重复运行的样本验收入口和人工兜底，但不以合成测试虚报真实准确率。
